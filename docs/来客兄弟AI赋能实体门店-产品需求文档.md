## §01 — 项目概述

### 1.1 项目背景

"来客兄弟"隶属中国数商科技旗下，专注实体门店 AI 化与短视频/直播数字化服务。当前实体门店面临客流下降、线上获客成本攀升、AI 工具渗透率低三大困境。本项目旨在通过"AI 赋能"主题落地页 + 小程序，作为沙龙推广投放的引流载体，将线上流量转化为预约线索，最终导入线下服务交付。

### 1.2 项目目标

| 维度 | 目标 |
|------|------|
| **引流** | 承接微信生态广告投放流量，每城市独立落地页精准承接当地用户 |
| **转化** | 6 大核心预约模块覆盖不同意向层级用户，预约数据实时同步需求方 |
| **传播** | "含 AI 量检测"小游戏激励社交分享，降低获客成本 |
| **品牌** | "要么 AI 化，要么被 AI 化"slogan 建立品牌心智 |

### 1.3 参考对标

本项目设计风格参考美国硅谷 [bayaiu.ai](https://bayaiu.ai/) 落地页，其核心特征：

- **极简叙事结构**: Hero → Syllabus → Faculty → Why → CTA，单一垂直滚动长页
- **清晰区隔**: `§01` `§02` 等章节编号 + 大量留白，信息密度适中
- **信任锚点**: 大学联合认证、讲师真人照片 + 真实履历、具体数据
- **单一 CTA**: 每个产品卡自带价格 + "Learn more"行动点，无复杂表单
- **深色专业风**: 深色背景 + 高对比文字，科技感强但不浮夸

来客兄弟将沿用此结构，但调整为更贴近中国实体门店老板审美的**淡蓝-淡紫清新风格**。

## §02 — 六大核心功能模块

> **核心定位**: 全部为**预约类申请**，非在线交易。用户提交预约 → 数据入库 → 异步通知需求发起方。

### 2.1 模块总览

| 编号 | 模块名称 | 目标用户 | 优先级 | 说明 |
|------|----------|----------|--------|------|
| M1 | 申请加入当地免费 AI 学联社社群 | 泛意向用户 | P0 | 门槛最低，最大化留资 |
| M2 | 申请参加 AI 沙龙 | 中意向用户 | P0 | 线下活动引流，筛选付费意向 |
| M3 | 申请参加 AI 游学 | 高意向用户 | P0 | 深度学习 + 社交场景，客单价高 |
| M4 | 申请参观未来城展厅 | 政府/企业决策者 | P0 | 信任背书，ToB 转化 |
| M5 | 报名 AI 普及线上课 | 线上用户 | P0 | 破地域限制，做用户基数 |
| M6 | 申请公益免费 AI 入企培训 | 企业主/管理层 | P0 | 0 成本获客，后续转化深度服务 |

### 2.2 各模块详细设计

#### M1 — AI 学联社社群

| 字段 | 内容 |
|------|------|
| **触发场景** | 用户看到广告 → 扫码/点击 → 落地页 → 填写申请 → 加入社群 |
| **表单字段** | 姓名（必填）、手机号（必填）、所在城市（下拉选择，必填）、门店类型（单选：餐饮/零售/美业/酒店/其他）、微信号（选填） |
| **提交后** | 展示社群二维码/群主微信号，同时后台通知运营人员拉群 |
| **特色** | 每个城市的社群独立运营，落地页按城市区分 |

#### M2 — AI 沙龙

| 字段 | 内容 |
|------|------|
| **触发场景** | 定期在各城市举办线下沙龙，用户预约席位 |
| **表单字段** | 姓名、手机号、城市（自动带入当前落地页城市）、门店名称、期望参加日期（备选场次）、同行人数 |
| **提交后** | 展示沙龙详情页（时间/地点/议程），短信通知 |
| **特色** | 支持"帮朋友报名"人数统计，每场限额显示 |

#### M3 — AI 游学

| 字段 | 内容 |
|------|------|
| **触发场景** | 深度游学产品，到标杆门店/AI 企业实地参观学习 |
| **表单字段** | 姓名、手机号、企业名称、职位、游学路线偏好（多选：AI 标杆门店/科技企业/产业园区）、预算区间 |
| **提交后** | 客服 1v1 对接，推送游学方案 |
| **特色** | 高价产品，不走自助流程，提交后人工跟进 |

#### M4 — 未来城展厅参观

| 字段 | 内容 |
|------|------|
| **触发场景** | 政府领导、企业决策者预约参观 AI 展厅 |
| **表单字段** | 姓名、手机号、单位名称、职务、预计来访人数、期望参观日期、关注方向（多选） |
| **提交后** | 生成预约确认函（可下载），安排接待人员 |
| **特色** | 展厅介绍页（图文/视频）作为预约前的"种草"内容 |

#### M5 — AI 普及线上课

| 字段 | 内容 |
|------|------|
| **触发场景** | 线上学习入口，破地域限制 |
| **表单字段** | 姓名、手机号、微信/邮箱 |
| **提交后** | 自动发送课程链接/兑换码，展示课程大纲 |
| **特色** | 免费或 9.9 元极低门槛，核心目的是获取用户到私域 |

#### M6 — 公益免费 AI 入企培训

| 字段 | 内容 |
|------|------|
| **触发场景** | 企业申请免费上门培训 |
| **表单字段** | 企业名称、联系人姓名、手机号、企业所在城市、员工规模、期望培训主题（多选）、期望时间范围 |
| **提交后** | 客服联系确认排期，匹配讲师资源 |
| **特色** | "公益免费"降低心理门槛，后续转化付费深度服务 |

### 2.3 统一预约流程

```
用户浏览落地页 → 选择感兴趣的模块 → 点击"立即预约"
    → 弹出预约表单（浮层/跳转）
    → 填写信息 → 提交
    → 后端入库 + 异步通知需求方（短信/企微/邮件）
    → 前端展示提交成功页（含下一步指引）
```

## §05 — 含 AI 量检测（小游戏）

### 5.1 产品定位

- **核心目的**: 增加页面趣味性 → 用户自发分享传播 → 降低获客成本
- **参考案例**: 网易云音乐年度报告、MBTI 人格测试等社交裂变型 H5
- **设计原则**: 3 分钟以内完成，结果可视化，一键分享到微信

### 5.2 检测流程

```
Step 1: 选择检测类型
  → "测我的含 AI 量"（个人版）
  → "测我们公司的含 AI 量"（企业版）

Step 2: 答题（5-8 题）
  个人版示例：
    - 你用 AI 写周报吗？（从不/偶尔/经常/全靠AI）
    - 你用 AI 做海报/图片吗？
    - 你用 AI 分析过经营数据吗？
    - 你关注了多少个 AI 相关的公众号/博主？
    - 你参加过 AI 相关的培训吗？
  
  企业版示例：
    - 公司有没有用 AI 客服/自动回复？
    - 营销素材是 AI 生成还是人工设计？
    - 库存/进货决策用了数据分析吗？
    - 员工有没有接受过 AI 工具培训？

Step 3: 生成结果页
  → 展示"含 AI 量"百分比 + 等级（如 "AI 青铜 / AI 白银 / AI 黄金 / AI 王者"）
  → 配一句点评文案（如："你的门店还在手工时代，隔壁老王已经用 AI 日省 3 小时"）
  → 展示来客兄弟可提供的提升建议（软性植入服务）
  → 一键分享按钮（生成带个人结果的分享海报）
```

### 5.3 分享海报设计

- 自动生成含用户检测结果的海报图片
- 海报内容：用户头像（微信授权）、含 AI 量等级、一句金句、小程序码/二维码
- 用户长按保存或直接转发到微信群/朋友圈
- 海报底部带"测测你的含 AI 量"引流文案 + 小程序码

### 5.4 技术要求

- 纯前端 H5 实现，不依赖后端（离线可用）
- 兼容微信内置浏览器
- 结果页用 Canvas 生成分享海报
- 用户答题数据可选入库（用于后续跟进）

```

                    ┌───────▼───────┐
                    │   API 服务     │
                    │ (Express 3002) │
                    └───────┬───────┘
                            │
              ┌─────────────┼─────────────┐
              │             │             │
        ┌─────▼─────┐ ┌────▼────┐ ┌─────▼─────┐
        │  SQLite   │ │  通知   │ │  日志     │
```

### 6.2 技术栈

| 层级 | 网页版 | 小程序版 |
|------|--------|----------|
| **前端框架** | 原生 HTML/CSS/JS（落地页轻量优先） | 微信原生框架 / Taro |
| **UI 风格** | 淡蓝-淡紫清新风，参照 bayaiu.ai 结构 | 与网页版统一视觉 |
| **后端** | Node.js + Express（共用） | 同一套 API |
| **数据库** | SQLite（轻量，后续可迁 MySQL） | 共用 |
| **部署** | Nginx 反向代理 → 腾讯云服务器 | 微信云开发 / 自建后端 |
| **通知** | 短信 + 企业微信 + 邮件 | 共用 |

### 6.3 数据字段（预约通用）

```sql
bookings:
  id              INTEGER PRIMARY KEY AUTOINCREMENT
  module          TEXT    -- M1~M6 对应六大模块
  name            TEXT    -- 姓名
  phone           TEXT    -- 手机号
  city            TEXT    -- 城市
  company         TEXT    -- 企业名称（选填）
  extra           TEXT    -- JSON，各模块特有字段
  status          TEXT    -- pending / contacted / confirmed / completed / cancelled
  source          TEXT    -- 来源渠道（落地页URL / 小程序）
  created_at      DATETIME
  updated_at      DATETIME
```

### 6.4 通知机制

预约提交后，异步通知需求方：

| 渠道 | 触发条件 | 内容 |
|------|----------|------|
| 企业微信 | 所有预约 | "新预约提醒：[模块名] - [姓名] [手机号]" |
| 短信 | 可选，高优先级模块 | 通知对应城市负责人 |

## §09 — FAQ 常见问题（页面展示用）

1. **来客兄弟是什么？**  
   来客兄弟是中国数商科技旗下品牌，专注实体门店 AI 化和短视频直播数字化服务。

2. **加入 AI 学联社社群收费吗？**  
   完全免费。按城市建群，群内分享 AI 工具、案例和本地活动信息。

3. **AI 入企培训真的是公益免费？**  
   是的。我们为符合条件的企业提供 2 小时的免费上门培训，不收取任何费用。

4. **沙龙和游学有什么区别？**  
   沙龙是 2-3 小时的线下分享活动（免费/低价）；游学是 1-2 天的深度参访学习（含标杆门店参观、实操演练）。

5. **含 AI 量检测准确吗？**  
   这是一个有趣的自我评估工具，结果仅供参考。如果想真正提升含 AI 量，欢迎预约我们的服务！

6. **可以同时报名多个模块吗？**  
   当然可以。社群、线上课、沙龙都可以同时参与。

7. **预约后多久有人联系我？**  
   提交后 1 个工作日内，城市负责人会通过电话或微信联系您。
